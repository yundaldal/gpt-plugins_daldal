### GitHub가 아직 연결되지 않았다면

- ChatGPT에서 GitHub 연결을 요청하면 안내에 따라 설정의 앱 또는 플러그인에서 GitHub 연결을 시작합니다.
- GitHub 계정으로 로그인합니다. 계정이 없다면 가입 화면의 **Continue with Google**을 통해 Google 계정으로 GitHub에 가입할 수 있습니다.
- GitHub 화면에서 ChatGPT 앱 설치·접근 권한을 확인하고 승인한 뒤, ChatGPT로 돌아와 연결 상태를 확인합니다. 필요한 저장소 접근 권한도 화면 안내에 따라 확인합니다.
- Plugin Creator를 선택한 채팅에 해당 플러그인의 설치 요청문을 다시 전달합니다. GitHub 연결은 저장소 접근을 위한 단계이며 플러그인 설치는 별도입니다. 메뉴·권한은 계정과 워크스페이스에 따라 다르며, URL로 설치할 수 없는 환경에서는 아래 ZIP 설치 안내를 이용합니다.

[ChatGPT의 GitHub 연결 안내](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt) · [Google 계정으로 GitHub 가입하기](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)

## 설치 안내

사용 전에 [플러그인별 업로드 요청과 사용자 입력 흐름](FLOW_MAPS.md)을 확인할 수 있습니다.

[무료·유료 계정별 설치 조건, ZIP 업로드, GitHub 마켓플레이스 가져오기](INSTALLATION.md)를 확인하세요. GitHub에서 ZIP을 내려받는 것만으로 ChatGPT에 자동 설치되지는 않습니다.

ZIP 다운로드, 워크스페이스 업로드, 사용자 설치는 각각 별도 단계입니다. 업로드는 플러그인을 워크스페이스에 등록합니다. 설치 정책이 **사용 가능(Available)**이면 각 사용자가 플러그인 디렉터리에서 **플러그인 설치(Install plugin)**를 눌러야 하고, 관리자가 **설치됨(Installed)** 정책을 설정하면 대상 사용자에게 자동 설치됩니다. 자세한 절차는 [설치 안내](INSTALLATION.md)를 참고하세요. 이 저장소 ZIP의 실제 ChatGPT 설치 흐름은 검증하지 않았으며, 메뉴와 권한은 계정·워크스페이스에 따라 달라질 수 있습니다. 배포 ZIP은 `downloads/`에서 제공합니다. GitHub Releases는 아직 구성하지 않았습니다.

## 품의 자료와 산출물 위치 선택

- **로컬 폴더에서 자료를 읽고 결과도 폴더에 저장하려면:** ChatGPT Desktop에서 프로젝트를 만들고, 프로젝트의 **Work** 또는 **Codex** 작업에서 사용할 로컬 폴더를 열어 접근을 허용합니다. 입력 자료를 해당 폴더에 두고, 산출물을 저장할 폴더 경로도 요청에 지정합니다. 프로젝트를 만들기만 해서는 PC 폴더가 자동 연결되지 않습니다.
- **무료 계정에서 자료를 프로젝트에 두고 반복해서 쓰려면:** ChatGPT 프로젝트를 만들고 PC의 `source` 폴더에서 지원되는 파일을 프로젝트 자료로 하나씩 올립니다. 프로젝트는 PC 폴더 자체를 연결하지 않습니다. Free 계정은 현재 프로젝트마다 파일 최대 5개이며, 플러그인 사용 가능 여부는 별도 설치·계정 조건에 따릅니다. 결과는 프로젝트 채팅의 답변이나 다운로드 파일로 나오며 PC의 `output` 폴더에는 자동 저장되지 않습니다.
- **프로젝트에서 로컬 폴더를 열지 않고 작업하려면:** 품의 자료를 해당 채팅창에 첨부합니다. 결과는 같은 채팅의 답변이나 다운로드 파일로 제시되며, PC의 로컬 폴더에 자동 저장되지는 않습니다.

ChatGPT 웹은 PC의 로컬 폴더에 직접 접근할 수 없습니다. 데스크톱의 로컬 파일 접근은 앱·Work/Codex 권한과 폴더 접근 허용이 필요합니다. 프로젝트에 파일을 올리는 메뉴와 한도는 [ChatGPT 프로젝트 안내](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) 및 [파일 업로드 안내](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)를 참고하세요. 로컬 폴더 연결은 [ChatGPT Work와 Codex 안내](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)를 참고하세요.

## 독립 스킬: 대한민국 공문서 분석

이 자료는 ChatGPT 플러그인이 아니라 `SKILL.md`와 보조 스크립트로 구성된 독립 Skill입니다. 원본은 [korean-official-doc 저장소](https://github.com/yundaldal/korean-official-doc/tree/analyzer), 배포 ZIP은 [korean-official-doc-analyzer.zip](https://github.com/yundaldal/gpt-plugins_daldal/raw/refs/heads/main/downloads/korean-official-doc-analyzer.zip)에서 확인할 수 있습니다. 라이선스는 MIT입니다.

- **Claude 무료 계정:** 사용할 수 있습니다. **설정 → 기능**에서 **코드 실행 및 파일 생성**이 켜져 있는지 확인하세요. 새 화면에서는 **파일 생성 및 편집**으로 표시될 수 있으며, 무료 계정은 기본으로 켜져 있을 수 있습니다. ZIP을 받은 뒤 **사용자 정의 → 스킬 → + → + 스킬 만들기 → 스킬 업로드**를 차례로 누르고, 업로드한 스킬을 켜세요. 자세한 내용은 [Claude 한국어 공식 스킬 안내](https://support.claude.com/ko/articles/12512180-claude%EC%97%90%EC%84%9C-%EC%8A%A4%ED%82%AC-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)를 참고하세요.
- **ChatGPT 무료 계정:** 이 독립 Skill은 사용할 수 없습니다. `@plugin-creator`가 표시되더라도 계정과 현재 환경에서 Skill 등록을 지원하는지 별도로 확인해야 하며, 지원 여부를 보장하지 않습니다.

## 플러그인 형식

새로 추가한 6개는 외부 MCP 서버나 API 키를 요구하지 않는 Skills 전용 플러그인입니다. 사용자 요청에 맞는 지침과 참고자료를 ChatGPT에 제공합니다.

## 공개 자료 점검

학생 사례는 식별할 수 없는 합성 예시로 바꿨고, 학교·기관명·개인 이름·내부 문서번호와 Office 작성자 메타데이터를 정리했습니다. IEP 성취기준 데이터는 원본 표 본문을 보존했습니다. IEP 참고 PDF 캡처 5개는 공개 재배포 대신 주제와 작성 절차를 담은 자체 안내 자료로 대체했습니다.

예시와 시험용 입력은 가상 정보이며, IEP 성취기준표는 정확성을 위해 공식 기준 자료를 유지했습니다. 문서와 계산 결과는 검토용 초안이므로 원자료, 단가 적용 여부와 회계 요건을 담당자가 확인한 뒤 사용하세요.

## GitHub 마켓플레이스

워크스페이스 관리자는 [marketplace.json](.agents/plugins/marketplace.json)을 가져와 플러그인을 관리할 수 있습니다. 개인 요금제 사용자의 설치 기능과는 별개이며, 가져오기 후에도 각 워크스페이스의 접근 정책을 설정해야 합니다.

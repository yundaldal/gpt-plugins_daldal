## 다운로드 안내

원하는 플러그인의 **ZIP 다운로드**를 누르세요. `Code → Download ZIP`은 저장소 전체를 받는 기능입니다.

현재 배포 파일은 `downloads/` 폴더에 있습니다. GitHub Releases 배포는 아직 구성하지 않았습니다.

ZIP 다운로드와 ChatGPT 설치는 별개입니다. 설치 지원 여부는 사용하는 서비스와 계정 환경에 따라 확인해야 하며, 이 저장소의 ZIP으로 ChatGPT 설치 동작을 검증하지 않았습니다.

## 개인정보와 정확성

공개 플러그인의 예시와 검증 자료는 가상 정보입니다. 실제 공문 이미지, 품의 입력·출력 자료, 성명·계좌, 대화 기록, 인증 정보는 포함하지 않습니다. 문서와 계산 결과는 검토용 초안이며, 원본 자료·단가 적용 여부·회계 요건을 담당자가 확인한 뒤 사용하세요. 플러그인별 지원 범위와 설치 조건은 각 사용 안내를 참고하세요.

# 캔바 AI 코드 생성 프롬프트 생성기

수업 아이디어를 Canva AI 또는 Canva Code에 넣을 한국어 학습 게임 제작 프롬프트로 바꿉니다. 상호작용, 화면 흐름, 접근성, 반응형 동작과 오류 회복을 구체화합니다.

**분류:** Education & Research · **형식:** Skills 전용 플러그인 · **외부 앱 연결:** 없음

## 입력과 결과

- **입력:** 학년, 학습목표, 주제, 선호 게임 유형, 활동 시간, 접근성 요구
- **결과:** Canva AI/Canva Code에 바로 붙여넣을 게임 제작 프롬프트

## 사용 예시

> 초등 4학년 물 절약 수업용 10분 선택형 게임을 Canva Code로 만들 프롬프트를 써 줘. 키보드로도 조작되고 모바일 화면에 맞게 구성해 줘.

플러그인이 단계별 확인을 요청하면 정보를 검토한 뒤 다음 단계로 진행하세요.

## 무료·유료 계정 설치

- **무료 계정:** Plugins 디렉터리에서 이 플러그인의 `Install plugin`이 표시되는지 확인합니다. 표시 여부와 사용 가능 범위는 계정·지역·워크스페이스에 따라 달라질 수 있습니다.
- **유료 개인 계정:** 같은 경로에서 설치 가능 여부를 확인합니다. 유료 구독만으로 ZIP 업로드 권한이 자동 부여되지는 않습니다.
- **워크스페이스:** 관리자 권한이 있으면 ZIP을 업로드하거나 GitHub 마켓플레이스를 가져올 수 있습니다. 구체적인 경로는 [설치 안내](../../INSTALLATION.md)를 참고하세요.

## ChatGPT에서 사용

설치 후 관련 요청에 자동으로 사용될 수 있습니다. 직접 선택하려면 `@`로 플러그인을 부르거나, `+` 메뉴 또는 작성창의 **Plugins**에서 플러그인을 고르세요. 아래 예시 문장을 그대로 시작점으로 쓸 수 있습니다.

# 원본 양식에 입력하기

실행 경로는 이 스킬이 설치된 폴더를 기준으로 찾습니다. 개발자 PC의 절대 경로를 사용자에게 요구하지 않습니다. 두 원본은 `templates/`에 포함되어 있습니다.

ChatGPT 대화에서 파일을 만들 때는 Python 또는 Code Interpreter & Data Analysis 도구를 실제 호출합니다. 지침이나 코드를 답변으로 출력하는 것만으로는 파일이 생성되지 않습니다. 먼저 [runtime.md](runtime.md)의 자체 복원 실행본을 Python 도구에서 실행하고, 현재 대화에서 확인받은 데이터로 `generate_upload(confirmed_case, "/mnt/data")`를 호출합니다. runtime.md의 실행본에는 이 플러그인의 두 원본 양식과 같은 배포의 생성·검증기가 포함되어 있어 원본 경로를 사용자에게 묻지 않습니다.

`.xlsx` 생성은 추가 설치 없이 Python 표준 라이브러리로 처리합니다. `.xls` 생성에 필요한 모듈이 없으면 ChatGPT Python 도구에서 플러그인 루트 `requirements.txt`의 xlrd/xlutils/xlwt를 설치하고 다시 실행합니다. 새 통합문서로 원본을 재구성하지 않습니다.

```sh
python <skill-root>/scripts/build_upload.py case.json /mnt/data/에듀파인업로드.xls
```

경기도 외 지역은 출력 파일을 `에듀파인업로드.xlsx`로 지정합니다. 생성 경로는 사용 환경의 다운로드 가능한 작업 폴더를 사용합니다.

`<skill-root>`는 읽고 있는 SKILL.md의 실제 상위 폴더입니다. ChatGPT Python 도구에서 플러그인 디렉터리를 직접 읽을 수 있으면 위 명령을 실행합니다. 경기도 외 지역은 결과 확장자를 `.xlsx`로 지정합니다. 직접 읽을 수 없으면 runtime.md의 전체 Python 코드를 실행하고 같은 실행 세션에서 `generate_upload(confirmed_case, "/mnt/data")`를 호출합니다. 두 경로 모두 `/mnt/data`에 실제 파일을 만들고 검증해야 완료입니다.

경기도 XLS에서 모듈이 없다면 ChatGPT Python 실행 환경의 패키지 설치 기능으로 `xlrd==2.0.2 xlwt==1.3.0 xlutils==2.0.0`을 설치하고 재시도합니다. Python 도구를 실제 호출하기 전에 실행 불가를 단정하지 않습니다. 실제 도구 부재나 실행 오류는 그 결과대로 안내합니다.

입력 JSON 예시(가상 품목이며 실제 자료 대신 사용하지 않음):

```json
{
  "region": "경기도",
  "items": [
    {"내용": "색연필", "규격": "12색", "단위": "세트", "수량": 3, "예상단가": 2000}
  ]
}
```

- `region`: 사용자 선택을 `경기도` 또는 `경기도 외`로 정규화합니다. 서울·부산·대구·인천·광주·대전·울산·세종·강원·충북·충남·전북·전남·경북·경남·제주 약칭도 허용합니다. 알 수 없는 지역을 자동으로 경기도 외로 처리하지 않습니다.
- `items`: 확인된 품목만 포함합니다. `내용`, `규격`, `단위`, `수량`, `예상단가`가 필요합니다. 규격이 없다고 확인했다면 빈 문자열을 사용합니다. 합계 행이나 안내용 행을 품목으로 보내지 않습니다.
- 경기도 외는 `S2B물품번호`(문자열, 앞자리 0 유지), `수수료`(숫자)를 확인된 경우에만 추가할 수 있습니다. 순번은 1부터 생성하고 예상금액은 수량×단가로 계산한 숫자값으로 입력합니다. `예상금액`을 입력했다면 계산값과 일치해야 합니다. 별도 수수료를 예상금액에 임의 합산하지 않습니다.
- 할인·배송비·수당 등으로 계산값과 원자료가 다르면 생성 전에 사용자와 행별 값을 확인합니다. 금액 불일치를 임의 보정하거나 계산 수식을 넣지 않습니다.
- 경기도에는 S2B물품번호·수수료 입력 열이 없으므로 이 정보를 입력 JSON에 넣어 조용히 누락시키지 않습니다. 사용자에게 처리 방식을 확인합니다.
- 셀 문자열은 수식으로 실행하지 않습니다. 파일 이름의 확장자는 원본과 같아야 합니다.
- 생성기가 `validate_upload.py`로 저장 파일을 다시 열어 입력값·행 수·원본 구조를 검사합니다. 통과할 때만 최종 경로로 이동하므로 오류 후 남은 임시 파일을 완성본으로 전달하지 않습니다.
- 실제 파일 존재·크기·실행 성공을 확인한 후 반드시 다운로드 링크를 붙입니다. ChatGPT에서는 `/mnt/data`에 생성한 파일을 `sandbox:/mnt/data/실제파일명` 링크로 제공합니다. 경로만 언급하거나 생성 예정이라고 답하고 끝내지 않습니다.

파일과 함께 반드시 다음 문구를 제시합니다.

에듀파인에서 [파일]업로드를 통해 타이핑 없이 바로 행에 넣으세요.

# 원본 양식에 입력하기

실행 경로는 이 스킬이 설치된 폴더를 기준으로 찾습니다. 개발자 PC의 절대 경로를 사용자에게 요구하지 않습니다. 두 원본은 `templates/`에 포함되어 있습니다.

Python 환경에서 플러그인 루트의 `requirements.txt` 의존성을 설치한 뒤 실행합니다. `.xlsx`는 표준 라이브러리로 원본 ZIP의 데이터 행만 추가하고, `.xls`는 xlrd/xlutils/xlwt로 원본을 복사해 입력합니다. 신규 통합문서로 디자인하지 않습니다.

```sh
python -m pip install -r <plugin-root>/requirements.txt
python <skill-root>/scripts/build_upload.py case.json 에듀파인업로드.xls
```

경기도 외 지역은 출력 파일을 `에듀파인업로드.xlsx`로 지정합니다. 생성 경로는 사용 환경의 다운로드 가능한 작업 폴더를 사용합니다.

입력 JSON 예시(가상 품목이며 실제 자료 대신 사용하지 않음):

```json
{
  "region": "경기도",
  "items": [
    {"내용": "색연필", "규격": "12색", "단위": "세트", "수량": 3, "예상단가": 2000}
  ]
}
```

- `region`: 사용자 선택을 `경기도` 또는 `경기도 외`로 정규화합니다. 서울·부산·대구·인천·광주·대전·울산·세종·강원·충북·충남·전북·전남·경북·경남·제주 약칭도 허용합니다. 알 수 없는 지역을 자동으로 경기도 외로 처리하지 않습니다.
- `items`: 확인된 품목만 포함합니다. `내용`, `규격`, `단위`, `수량`, `예상단가`가 필요합니다. 규격이 없다고 확인했다면 빈 문자열을 사용합니다. 합계 행이나 안내용 행을 품목으로 보내지 않습니다.
- 경기도 외는 `S2B물품번호`(문자열, 앞자리 0 유지), `수수료`(숫자)를 확인된 경우에만 추가할 수 있습니다. 순번은 1부터 생성하고 예상금액은 수량×단가로 계산한 숫자값으로 입력합니다. `예상금액`을 입력했다면 계산값과 일치해야 합니다. 별도 수수료를 예상금액에 임의 합산하지 않습니다.
- 할인·배송비·수당 등으로 계산값과 원자료가 다르면 생성 전에 사용자와 행별 값을 확인합니다. 금액 불일치를 임의 보정하거나 계산 수식을 넣지 않습니다.
- 경기도에는 S2B물품번호·수수료 입력 열이 없으므로 이 정보를 입력 JSON에 넣어 조용히 누락시키지 않습니다. 사용자에게 처리 방식을 확인합니다.
- 셀 문자열은 수식으로 실행하지 않습니다. 파일 이름의 확장자는 원본과 같아야 합니다.
- 출력 후 다시 열어 입력값과 행 수를 비교합니다. `.xls`는 `xlrd`, `.xlsx`는 ZIP/XML 또는 사용 환경의 Excel 읽기 도구로 검사할 수 있습니다.

파일과 함께 반드시 다음 문구를 제시합니다.

에듀파인에서 [파일]업로드를 통해 타이핑 없이 바로 행에 넣으세요.

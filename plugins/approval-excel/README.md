# 품의기안문과 첨부엑셀파일을 생성하는 AI (학교용)

견적서나 품목 목록을 분석해 학교 품의 문안과 지역별 원본 양식의 입력 칸만 채운 에듀파인 업로드용 Excel을 작성합니다. 파일 근거와 금액 산식을 대조합니다.

**분류:** Productivity · **형식:** Skills 전용 플러그인 · **외부 앱 연결:** 없음

## 입력과 결과

- **입력:** 견적서(PDF, JPG, PNG, BMP, DOC, DOCX, TXT), 장바구니 텍스트 또는 직접 입력한 품목·수량·단가·용도
- **결과:** 품의 문안과 지역별 원본 양식에 값만 입력한 Excel 파일

## 사용 예시

> 첨부한 견적서와 행사 목적을 바탕으로 품의문과 업로드용 Excel을 만들어 줘. 품목 수량, 단가, 합계가 원문과 계산식에 맞는지 확인해 줘.

플러그인이 단계별 확인을 요청하면 정보를 검토한 뒤 다음 단계로 진행하세요.

## 무료·유료 계정 설치

- **무료 계정:** Plugins 디렉터리에서 이 플러그인의 `Install plugin`이 표시되는지 확인합니다. 표시 여부와 사용 가능 범위는 계정·지역·워크스페이스에 따라 달라질 수 있습니다.
- **유료 개인 계정:** 같은 경로에서 설치 가능 여부를 확인합니다. 유료 구독만으로 ZIP 업로드 권한이 자동 부여되지는 않습니다.
- **워크스페이스:** 관리자 권한이 있으면 ZIP을 업로드하거나 GitHub 마켓플레이스를 가져올 수 있습니다. 구체적인 경로는 [설치 안내](../../INSTALLATION.md)를 참고하세요.

## ChatGPT에서 사용

설치 후 관련 요청에 자동으로 사용될 수 있습니다. 직접 선택하려면 `@`로 플러그인을 부르거나, `+` 메뉴 또는 작성창의 **Plugins**에서 플러그인을 고르세요. 아래 예시 문장을 그대로 시작점으로 쓸 수 있습니다.

## 대화 진행 방식

유형 선택 → 입력 방법 안내 → 자료·금액 확인 → 품의문·엑셀 생성 → 수정. 분석 결과를 확인받은 뒤 파일을 만듭니다.

## 0.14.3: 지역별 에듀파인 원본 양식

지역을 먼저 확인합니다. 경기도는 포함된 `엑셀산출파일 경기도.xls`, 경기도 외 시도교육청은 `엑셀산출파일 경기도외 시도교육청.xlsx`에 작성합니다. 원본 열·시트·기존 서식을 보존하고 입력 행만 채웁니다. 총합계·소계·설명·추가 시트는 넣지 않습니다. 경기도 외 양식의 기존 예상금액 열에는 품목별 금액만 입력합니다.

에듀파인에서 [파일]업로드를 통해 타이핑 없이 바로 행에 넣으세요.

실행 환경에서는 `requirements.txt` 의존성을 설치하고 [입력·실행 안내](skills/instructions/upload-guide.md)를 따릅니다. 원본이나 실행 도구를 사용할 수 없으면 임의의 양식으로 대체하지 않습니다.

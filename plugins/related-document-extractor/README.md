# 관련 공문 정보 추출기

에듀파인 공문 목록 이미지에서 문서번호, 결재완료 날짜, 제목을 추출하는 지침 기반 플러그인입니다.

## 활용 방법

- 문서번호·제목·결재완료일시가 보이도록 화면을 캡처합니다.
- 플러그인이 활성화된 채팅에 이미지를 붙여넣습니다.
- 출력된 문서번호와 날짜를 원본과 대조한 후 사용합니다.

## 출력 형식

`가상교육과-1001(2025.4.9.) 가상 교원 연수 결과 안내`

## 다운로드와 설치

ZIP은 배포용 파일입니다. 다운로드만으로 ChatGPT에 설치되지는 않습니다. 설치 가능 여부와 절차는 사용하는 서비스의 플러그인 지원 및 계정 환경에 따라 확인해야 합니다. 이 저장소에서는 ChatGPT 설치 동작을 검증하지 않았습니다.

## 공개 범위와 주의 사항

- 제작자 표시를 달달샘으로 변경하고 예시를 가상 정보로 교체한 공개용 사본입니다.
- API 키, 비밀번호, 실제 업로드 공문, 대화 기록은 포함하지 않습니다.
- 지침에는 불명확한 정보를 추론하도록 하는 기존 동작이 남아 있습니다. 숫자·날짜는 반드시 원본으로 확인하세요.
- 개인정보 마스킹은 AI에게 주는 지침이며 자동 보안을 보장하는 프로그램이 아닙니다. 민감한 정보는 업로드 전에 가리세요.
- 기존에 설치된 플러그인은 변경하지 않았습니다.

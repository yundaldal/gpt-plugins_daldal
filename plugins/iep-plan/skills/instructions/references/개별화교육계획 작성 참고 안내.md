# 개별화교육계획(IEP) 작성 참고 안내

이 자료는 특정 학생이나 기관의 기록을 포함하지 않는 일반 작성 안내입니다. 실제 계획은 사용자가 제공한 학생 정보와 해당 교육과정 기준표를 확인해 작성합니다. 확인되지 않은 이력·진단·성취기준을 추측해 채우지 않습니다.

## 계획 수립 흐름

1. 학생의 강점, 흥미, 의사소통 방식, 학습 환경과 지원 요구를 확인합니다.
2. 현재 수행 수준을 관찰 가능한 행동과 조건으로 기록합니다. 학부모 및 교직원 의견, 이전 기록이 제공되면 출처와 시점을 구분합니다.
3. 현재 수준과 교육과정 성취기준을 대조하고, 실제 기준표에서 과목·교육과정 구분·학년군·분류번호·기준 문구를 확인합니다.
4. 장기 목표와 측정 가능한 세부 목표를 세우고, 필요한 특수교육·관련 서비스·보조공학·환경 조정을 연결합니다.
5. 목표를 월별 교육내용과 교수 방법으로 나누고, 수행 기회·촉진 수준·자료·평가 방법을 정합니다.
6. 담당자와 점검 시점, 진전 기록 방법을 명확히 하고, 계획 실행 후 자료에 근거해 목표와 지원을 검토합니다.

## 계획에 포함할 정보

- 현재 수행 수준: 강점, 독립 수행, 필요한 촉진·도구, 관찰 조건
- 교육 목표: 장기 목표, 단계별 세부 목표, 연결한 성취기준과 적용 근거
- 교육 내용과 방법: 월별 학습 내용, 직접 교수·모델링·시각 자료 등 학생 특성에 맞는 전략
- 평가 계획: 관찰 가능한 성공 기준, 기록 도구, 평가 시점과 결과 검토 방식
- 지원과 참여: 특수교육 및 관련 서비스, 보조공학, 접근성 조정, 가정·학교 협력과 학부모 의견
- 운영 정보: 담당 역할, 배치·교육환경, 회의에서 합의한 사항, 전환 지원이 필요한 경우의 연계 계획

핵심 확인 항목은 현재수준(현행수준), 장기목표, 단기목표, 연간목표, 월별 교육내용, 교육방법, 평가계획, 성취기준, 학생 참여, 협력, 학부모 의견, 장애 특성, 전환 지원, 관련서비스, 책임자, 배치, 회의입니다.

## 목표와 평가의 일치

각 목표는 학생이 무엇을, 어떤 조건에서, 어느 정도 수행하면 달성으로 볼지 드러나게 작성합니다. 세부 목표의 난이도는 현재 수준에서 다음 단계로 이어지도록 배열합니다. 평가 도구와 성공 기준은 목표 행동을 직접 관찰할 수 있어야 하며, 결과에는 지원 수준과 수행 맥락을 함께 기록합니다.

## 월별 교육계획 점검

월별 교육내용은 목표와 연결하고, 학기 초·전환기·방학 시기에는 실제 수업 가능 시간을 고려합니다. 교수 방법은 학생의 강점과 지원 요구에 맞게 선택합니다. 평가 자료를 정기적으로 검토해 진전이 없거나 목표를 달성한 경우에는 필요한 지원과 다음 단계를 조정합니다.

## 품질 확인

- 현재 수준, 목표, 교육내용, 방법, 평가가 서로 연결되어 있는가
- 성취기준의 분류번호와 문구를 기준표에서 직접 확인했는가
- 학부모 의견과 학생의 선호·의사소통 방식이 계획에 반영되었는가
- 역할·서비스·배치·전환 지원과 점검 책임이 명확한가
- 문장과 예시에서 실제 학생·가족·학교를 알아볼 수 있는 정보가 제거되었는가

## 범위

이 안내는 계획의 작성 흐름과 검토 항목을 설명합니다. 법령·교육과정 기준이나 학교별 양식을 대신하지 않으며, 해당 연도에 적용되는 공식 기준과 기관 절차를 확인해야 합니다.

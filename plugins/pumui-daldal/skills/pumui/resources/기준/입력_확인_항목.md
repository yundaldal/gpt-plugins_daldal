# 품의 자료 확인 항목

자료에서 값을 읽었더라도 다음 항목은 사용자에게 읽은 내용이나 선택을 확인합니다. 모르는 값은 추측하지 말고 한 번에 모아 질문합니다.

- 추천 품의 유형: 원본 절차에 따라 추천 유형과 근거를 먼저 제시하고 한 번 확인
- 관련 문서: 문서번호·날짜·제목. 실제로 없을 때는 없음을 확인
- 지급 대상: 이름·소속·직위·계좌 정보와 소득 구분. 결과 보고서와 대조하되 계좌를 로그나 오류 설명에 표시하지 않음
- 수당: 강사·그룹·컨설팅·위원 분류, 회차별 인정시간, 원고 종류·매수·규격·재활용 비율, 교통비
- 강사료 할증: 참고 단가 자료의 해당 인원 구간과 적용 여부, 적용 근거·비율. 자동으로 할증하지 않으며 최종 금액을 다시 확인
- 물품: 품명·규격·수량·단위·단가 및 품의 총액
- 경비: 사용 목적·대상·장소·항목별 단가·수량 인자와 산출식
- 관련 붙임: 준비 완료·추후 첨부·해당 없음 중 사용자 확인 상태
- 적용 단가: A유형의 참고 프로필 연도와 기관 적용 여부

읽을 수 없거나 OCR 결과가 불확실한 HWP·스캔·PDF는 읽었다고 하지 않습니다. 지원되는 읽기 방법을 안내하거나 필요한 값만 직접 입력해 달라고 합니다.

# 기안문 작성 규칙

## 제목과 날짜

- 제목은 항상 `[품의] `로 시작합니다. 기존 접두어가 있으면 중복하지 않습니다.
- 날짜는 `YYYY. M. D.(요일)` 형식으로 씁니다. 월·일 앞의 0을 생략하고 실제 요일을 확인합니다.
- 시간 범위와 날짜 범위의 물결표는 앞뒤를 붙여 씁니다. 예: `시작~끝`.

## 본문

- 기호 순서는 `1.` → `가.` → `1)` → `가)` → `(1)` → `(가)`입니다. 산출식 같은 세부 줄에는 `-`를 씁니다.
- 관련 문서, 목적 문장, 본문 항목의 이름과 순서는 확인된 유형의 구성표를 따릅니다. 확인되지 않은 번호·날짜·장소·대상·금액은 만들지 않습니다.
- 목적 문장은 `~하고자 합니다.`로 끝냅니다.
- 금액은 계산 결과를 사용하며, 계산 전 본문 초안에는 금액을 임의로 적지 않습니다.
- 문단 사이 빈 줄과 둘째 줄 들여쓰기를 유지합니다. 탭 문자나 특수 공백을 사용하지 않습니다.
- 문서 마지막은 `끝.`으로 마칩니다.

## 붙임

- 첫 붙임은 유형별 구성표의 지출품의서 명칭을 따릅니다. 이번 범위에서 지출품의서는 생성하지 않으며, 사용자가 나중에 첨부하는 상태를 표시합니다.
- 생성한 엑셀은 유형별 구성표의 순서·이름으로 붙임에 적습니다. 조건에 해당하지 않는 선택 붙임은 넣지 않습니다.
- 원고 파일은 만들지 않습니다. 필요한 경우 이름만 붙임에 적고, 사용자가 업무시스템에 직접 올리도록 안내합니다.

## 산출식과 표기

- 한 기안문 안에서 곱셈 산출식 표기를 통일하고 단가×수량 인자=금액이 맞는지 확인합니다.
- 하위 항목 금액의 합계와 해당 소요 금액이 다르면 임의로 맞추지 말고 확인 질문을 합니다.
- HWPX 출력은 포함된 바탕 양식과 작성기를 사용합니다. 생성 후 컨테이너·문서 구조와 주요 내용을 검사합니다.

# 품의 입력 구조

이 문서는 실행기가 받는 `case.json` 구조를 설명합니다. 품의 1건마다 새 입력을 만들고, 과거 건의 값이나 공개 예시를 복사하지 않습니다. 실제 이름·계좌·기관 자료는 GitHub·검증 파일에 넣지 않습니다.

## 최상위 필드

| 필드 | 의미 |
|---|---|
| `case_id` | 품의 건을 구분하는 식별자. 공개 저장소에는 더미 값만 사용 |
| `type` | `A1`~`A4`, `B1`~`B2`, `C1`~`C3` 중 사용자 확인을 받은 유형 |
| `department` | 담당 부서 |
| `draft` | 제목, 관련 문서, 목적, 본문 항목, 붙임 |
| `allowance` | A1~A3 강사, A4 컨설팅 또는 위원회 수당 대상·분류·회차·인정시간·원고·교통비 입력 |
| `purchase` | 물품명·규격·수량·단위·단가 입력. C3에서는 물품 내역이 있을 때만 사용 |
| `expense` | C유형 경비 항목·단가·수량 인자·입력 금액 |
| `user_status` | 붙임마다 `ready`, `later`, `na`로 기록한 사용자 확인 상태 |
| `computed` | 계산기가 채우는 값. 직접 만들어 쓰지 않음 |

실제 품의의 관련 문서가 없으면 사용자가 없음을 확인한 뒤 `draft.related`를 빈 목록 `[]`으로 둘 수 있습니다. 확인 없이 빈 목록으로 처리하지 않습니다.

## 금액과 C3 혼합 입력

- 기안문 금액 필드는 비워 둡니다. 계산기가 산출한 합계 문구를 기안문 작성기가 넣습니다.
- `purchase.items`의 행 금액은 수량×단가, 경비 행 금액은 단가×각 수량 인자입니다. 입력된 별도 금액이 계산 결과와 다르면 정정·확인을 요청합니다.
- C3에 경비와 물품이 모두 있으면 두 영역을 각각 기록합니다. 원본 규칙대로 기안 총액은 계산기의 총액 우선순위(수당→경비→물품)를 따르고, 에듀파인 예산연결 업로드 행은 물품이 있으면 물품 목록을 사용합니다.
- 혼합 C3에서 기안 총액과 업로드 행 합계가 다르면 두 금액을 임의로 합치거나 어느 쪽도 조정하지 않습니다. 범위·예산 반영을 사용자에게 확인하고, 일치가 확인되기 전에는 결과 생성을 멈춥니다.
- 에듀파인 예산연결 업로드 양식은 `단위` D열을 비워 둡니다. 물품 구입 목록 등 별도 출력물의 단위는 보존합니다.
- 엑셀 금액·합계는 수식 문자열만 남기지 않고 미리보기에서 읽히는 숫자값으로 기록합니다.

## 계산 결과

`computed`에는 총액, 읽기 쉬운 총액 문구, 사람별 계산, 물품·경비 계산, 경고(`warnings`), 확인 질문(`questions`)이 들어갑니다. 확인 질문이 남으면 기안문·엑셀을 생성하지 않습니다. 경고도 사용자에게 보여 주고 필요한 판단을 받습니다.

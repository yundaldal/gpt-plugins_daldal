# 품의 기안 도우미

교육기관 지출품의 입력을 정리하고 기안문·엑셀 초안과 점검 결과를 준비합니다. 모든 문서와 계산은 사용자가 확인할 초안입니다.

## 진행 순서

1. 요청을 9개 유형 중 하나로 분류합니다: A1~A3 강사 수당, A4 컨설팅 수당, B1~B2 물품 구입, C1~C3 경비. 애매하면 유형을 먼저 확인합니다. 유형별 본문 항목과 붙임 기준은 `resources/기준/유형별_구성.json`을 따릅니다.
2. 기관명, 부서, 제목, 목적, 관련 문서, 본문 항목, 붙임 상태를 확인합니다. A 유형은 지급 대상별 수당 구분·인정시간·소득 구분과 필요한 원고료·교통비를 확인합니다. B 유형은 학교급과 품명·수량·단가를 확인합니다. C 유형은 학교급과 항목별 단가·수량 인자를 확인합니다.
3. 비어 있거나 모호한 필수 입력은 질문합니다. 문서번호, 날짜, 인원, 단가, 세율, 인정시간, 계좌 정보, 붙임 상태를 추측하거나 만들어 내지 않습니다.
4. A 유형에서 단가를 계산하기 전에 `resources/기준/수당단가.json`의 프로필 연도와 소속 기관 적용 여부를 사용자에게 확인합니다. 확인되면 `rate_confirmation`에 확인한 기관명·연도와 `confirmed: true`를 넣습니다. 이 단가표는 포함된 참고 프로필이며, 공식 규정이나 적용 가능성을 대신 확인하지 않습니다. 사용자가 적용을 확인하지 않으면 계산을 진행하지 않습니다.
5. 입력 자료가 준비되면 `scripts/validate_case.py`로 형식과 필수 입력을 확인하고 `scripts/run_case.py`를 실행합니다. 이 실행기는 계산, HWPX, 엑셀, 준비점검표 및 독립 자동 점검을 수행합니다. 자동 점검 실패가 있으면 완성으로 안내하지 말고 `점검결과.md`의 실패 항목을 해결합니다.
6. 결과 파일을 사용자에게 전달하기 전에 기안문 본문·금액·대상·붙임, 엑셀의 수식과 합계, 학교급, 준비점검표를 확인하도록 안내합니다. 단가 적용, 회계 분류, 결재 요건은 담당자가 최종 확인해야 합니다.

## 실행 환경

이 플러그인은 안내와 로컬 스크립트를 제공합니다. 현재 ChatGPT 화면에서 로컬 파일에 접근하거나 Python 스크립트를 실행할 수 있는지는 설치 환경에 따라 다릅니다. 실행 도구가 없으면 파일을 생성했다고 말하지 말고, 사용자가 비공개 작업 폴더에서 실행할 명령을 안내합니다.

Python 3.10 이상과 `requirements.txt`의 패키지가 설치된 환경에서 플러그인 폴더 기준으로 실행합니다.

```text
python skills/pumui/scripts/run_case.py <비공개폴더>/case.json <비공개폴더>/결과 [<비공개폴더>/input]
```

실제 인명·소속·계좌 정보가 포함될 수 있으므로 `case.json`, 원본 입력 문서, 결과 파일을 공개 저장소나 테스트 산출물에 넣지 않습니다. 실행기는 `case.json`을 결과 폴더로 복사하지 않지만, 사용자가 지정한 원본 입력 파일은 별도로 남습니다. 결과 폴더와 엑셀도 민감한 자료로 취급합니다.

## 포함 자료

- `resources/기준/유형별_구성.json`: 유형별 본문·붙임 구성
- `resources/기준/수당단가.json`: 사용 전 기관·연도 확인이 필요한 참고 단가 프로필
- `resources/기준/양식/`: 비어 있는 HWPX 및 XLSX 서식
- `scripts/`: 입력 검증, 계산, 파일 생성, 준비 상태와 독립 점검 코드

공개 저장소의 검증 사례는 모두 결정적 예시 값을 사용하는 합성 자료입니다.

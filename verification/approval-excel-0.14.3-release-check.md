# approval-excel 0.14.3 변경 기준과 검증

## 암묵지 확인

- 업로드 파일은 지역별 원본 양식에 값을 채우는 문서다. 보기 좋은 일반 명세서로 다시 디자인하지 않는다.
- 경기도 `.xls`는 5열이며 금액 열이 없다. 경기도 외 `.xlsx`는 9열이며 품목별 예상금액 열이 있다. 후자의 예상금액 입력과 별도 총합계 행 생성은 구분한다.
- 원본의 기존 제목·빈 행·병합은 보존한다. 추가 제목·총합계·소계·수식·설명·출처·시트는 넣지 않는다.
- 지역 미확인 시 질문한다. 이미 명시된 지역은 재질문하지 않는다. 지역 변경 시 해당 원본부터 다시 생성한다.
- 단위·수량·단가 등 미확인 값을 만들지 않는다. S2B물품번호·수수료의 빈칸을 임의의 값으로 채우지 않는다.
- 지정 안내 문구는 파일 밖에 제시한다: 에듀파인에서 [파일]업로드를 통해 타이핑 없이 바로 행에 넣으세요.

| --- | --- |
| 대상·원본 확인 | approval-excel 식별, 사용자 제공 원본 두 파일을 바이트 그대로 포함 |
| 구현 | 지역 선택, 원본별 열 제한, 생성 스크립트, 참고문서보다 우선하는 제한, 0.14.3 버전 |
| 하네스 | 양 지역 생성 파일 재열기, 값·헤더·시트·병합·원본 구조 검사, 지역/금액/열 오류 거부 |
| 배포 | 대상 ZIP과 소스 바이트 일치, 다른 플러그인 변경 없음, GitHub main 업로드 |

## 실행 검사

`python -m unittest verification/test_approval_upload.py -v`: 6개 통과. 두 품목을 실제 파일로 생성해 읽고 경기도 5열/3행, 경기도 외 9열/5행을 확인한다. 경기도 외는 변경 대상 sheet1.xml 외 모든 ZIP 멤버가 원본과 바이트 동일하다. 기존 헤더 행도 보존한다. 문자열의 수식 비실행, S2B 앞자리 0, 선택값 공란, 지역 변경, 잘못된 확장자, 불일치 금액·불필요한 열의 거부를 검사한다.

경기도 XLS는 xlutils 복사 과정에서 테두리가 없는 변의 사용되지 않는 색상 번호가 정규화될 수 있다. 검사는 실제 테두리 유무와 표시되는 색, 정렬, 열 너비, 헤더, 셀값을 비교한다.

`npm --prefix verification test`: 대상 플러그인의 매니페스트·지침·기존 자료 보존 검사는 통과. 전체 하네스는 기존 기준 커밋 `482b406` 이후 이미 게시된 `pumui-daldal` 변경 때문에 `Excluded plugin and marketplace unchanged`에서 실패한다. 이번 작업의 기준은 동기화한 `b29d7ac`이며 다른 플러그인을 수정하거나 기존 검사를 완화하지 않는다.

이 검증은 스크립트·파일·정적 지침 검사다. 실제 ChatGPT 대화 실행 및 에듀파인 서버 업로드는 수행하지 않았으므로 업로드 성공을 입증한 것으로 보지 않는다.
